# Agentic AI Engineering

Developing practical AI applications and agentic systems using Python, Large Language Models (LLMs), and modern AI engineering tools.

## Core Areas

* Python application development
* Data validation and structured outputs
* Asynchronous programming and API integration
* LLM application development
* Tool calling and agent workflows
* Retrieval-Augmented Generation (RAG)
* Workflow orchestration and state management
* Testing, evaluation, security, and deployment

## Repository Structure

* `practice/` — Focused implementations of individual engineering concepts.
* `projects/` — Complete AI applications and agentic systems.
* `notes/` — Technical documentation and implementation references.

## Technology Stack

* Python
* Pydantic
* FastAPI
* LLM APIs
* Git and GitHub

Additional technologies will be introduced as the applications evolve.

## Engineering Principles

* Build modular, maintainable applications.
* Validate inputs and handle errors explicitly.
* Test critical functionality.
* Evaluate AI outputs rather than relying on assumptions.
* Protect credentials and sensitive information.
* Document design decisions and technical trade-offs.
